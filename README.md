# GGFlix Web App with Built-in Ad Blocker

Welcome to the **GGFlix Web App**, a simple and responsive web application that lets you enjoy the **GGFlix** streaming site without the distractions of ads. This app loads **https://ggflix.ru** within an iframe, and it comes with a built-in **ad blocker** that dynamically removes ads, popups, and any unwanted content to provide a smooth and uninterrupted viewing experience.

## 🌟 Features

- **Strict Ad Blocking**: Automatically removes ads, popups, and embedded ad frames from the site.
- **Responsive Design**: The app is fully responsive, ensuring a great experience on desktop, tablet, and mobile devices.
- **Seamless Integration**: GGFlix is loaded inside an iframe to isolate the original site while ensuring compatibility with the ad-blocking script.
- **Real-time Ad Removal**: Ads are blocked as soon as they load, keeping the viewing experience ad-free throughout your session.
